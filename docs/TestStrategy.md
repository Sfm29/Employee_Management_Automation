# Test Strategy

## Project Overview

This project aims to automate the main business workflows of an Employee Management System using Playwright and TypeScript.

The objective is to demonstrate modern QA Automation practices through a scalable and maintainable automation framework.

---

# Objectives

- Validate critical business workflows.
- Reduce manual testing effort.
- Improve regression testing.
- Build a reusable automation framework.
- Demonstrate enterprise automation practices.

---

# Scope

The following modules will be automated:

- Authentication
- Dashboard
- Employee Management
- User Administration
- Recruitment
- Leave Management
